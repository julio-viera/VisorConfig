# Visor Config 1.0.0

The first release of Visor Config brings configuration file editing, validation, and comparison into one app.

- Open JSON, JSONC, YAML, TOML, INI, dotenv, and Java Properties files in separate tabs. Each tab keeps its own format and schema.
- Edit in the text view with syntax highlighting and line numbers. Format or minify the document, inspect and edit values in the tree view, explore the structure in the graph and radial views, or edit lists of objects with matching fields in a table.
- Search by text or JSONPath. The status bar shows syntax errors, and you can validate JSON documents against a JSON Schema.
- Compare two tabs side by side and navigate between highlighted differences.
- Convert data to JSON, YAML, TOML, INI, dotenv, or Java Properties when the target format supports the source structure. Export tables as CSV and the visible graph as PNG or SVG.
- Follow the system theme or choose light or dark mode. Adjust the color palette, font, and font size. The interface is available in English, Spanish, French, Portuguese, German, and Italian.

The project provides build scripts for DEB, RPM, Flatpak, and Snap packages on Linux. [Packaging instructions (Spanish)](../tools/README.md) · [User guide](../README.md)
